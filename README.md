# EXP BLOG APP - Backend learning Project

A backend-focused learning project built as part of my journey into backend engineering.

This is my first backend application, created to gain practical experience with server-side development, database integration, MVC architecture, authentication, data handling, and industry-standard development workflows.

---

## Project Overview

The goal of this project is to understand backend development fundamentals with building a real-world application from scratch.

Through this project, I am learning how to:

- Build server-side applications with Node.js and Express.js
- Design and develop REST APIs
- Work with MongoDB databases using Mongoose
- Implement MVC architecture
- Handle user authentication and authorization
- Manage data validation and error handling
- Render dynamic views using EJS
- Follow clean code and backend development best practices

---

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS

---

## Learning Goals

This project is focused on understanding:

- Backend architecture fundamentals
- Database modeling and relationships
- Request-response lifecycle
- Authentication and session management
- Server-side rendering
- Error handling strategies
- Clean and maintainable code practices
